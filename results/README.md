# Results

Generated by the SegLens pipeline. Subdirectories:

- `depth_curves/` — Dice/IoU per stage for the 3 lenses
- `concept_scoring/` — CAV tensors and per-image concept scores
- `ablation/` — ΔDice table when ablating each CAV at each stage
- `universeg_baseline/` — UniVerSeg predictions for the same test set

The `*.png`, `*.pt` and `*.pth` files are gitignored. Re-run with
the corresponding `make` target or `uv run seglens-*` command.
